# Week 5 — Server Side Foundations with Docker & DevOps Basics

## Objective

The objective of Week 5 is to understand how production servers work by using Docker to simulate deployment environments locally.

The week covers:

* Docker fundamentals
* Linux internals inside containers
* Docker Compose
* Multi-container applications
* Docker networking
* Persistent volumes
* NGINX reverse proxy
* Load balancing
* SSL/TLS
* HTTPS
* CI-style deployment automation
* Production-style Docker configuration

---

# Day 3 — NGINX Reverse Proxy + Load Balancing

## Topics to Learn

* [ ] NGINX inside Docker
* [ ] Reverse proxy
* [ ] Routing requests to internal containers
* [ ] Backend replicas
* [ ] Load balancing
* [ ] Round-robin load balancing

## Required Architecture

Run two instances of the backend.

```text
                     ┌──> Backend Instance 1
                     |
Client ──> NGINX ────┤
                     |
                     └──> Backend Instance 2
```

NGINX acts as the reverse proxy.

## Required Routing

Configure:

```text
/api → backend-service:3000
```

## Main Exercise

* [ ] Create an NGINX container
* [ ] Run backend instance 1
* [ ] Run backend instance 2
* [ ] Put NGINX and backend containers on the appropriate Docker network
* [ ] Configure NGINX as a reverse proxy
* [ ] Configure `/api` routing
* [ ] Enable round-robin load balancing
* [ ] Send multiple requests
* [ ] Verify requests are distributed between backend instances

## Day 3 Deliverables

```text
reverse-proxy-readme.md
```

## Day 3 Completion Check

## 2. Environment Configuration

Use:

```text
.env
```

for secrets/configuration.

* [ ] Store required secrets in `.env`
* [ ] Do not hard-code secrets into configuration files
* [ ] Ensure `.env` is not committed to Git

Example Git protection:

```text

```

should be included in `.gitignore`.
